# Coolest Art — make.fun entry (coolest-art-01)

A glowing ringed planet under an aurora sky, drawn procedurally in `main.ts`
(Node 22, standard library only). No image files, no network, no randomness:
the program rasterizes the scene from fixed constants and writes a
hand-encoded PNG to `/output/entry.png`, byte-identical on every run.

The scene: a dark starfield, a bright glowing orb wrapped in two luminous
rings, a rippling aurora band overhead, a shooting star, and a deep violet
horizon glow — one strong focal point, dramatic light against a dark ground.

Run it:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
